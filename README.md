# Unity 3D Interactive Experience

## Overview
Interactive Unity project with movement, terminal interaction, and UI controls to modify the environment in real time.

## Controls
- WASD: Move
- Mouse: Look
- Right Click: Lock cursor
- ESC: Unlock cursor
- E: Interact

## Features
- Terminal UI toggle
- Change time of day (Day/Night/Sunset)
- Adjust jump height (slider)
- Change movement speed (in-world selection)
